## Лабораторная №1. "Создание Test Case"

### TestCase #1: Добавление каталога на основном экране при помощи функционала центральной области

| **Номер**       | 1                                                                                         |
|:--------------- |:------------------------------------------------------------------------------------------|
| **Заголовок**   | Создание каталога.                                                                        |
| **Предусловие** | Открыта страница [сайта](https://disk.yandex.ru/client/disk). Пользователь зарегистрирован. В переменных окружения DISK_USERNAME, DISK_PASSWORD, DISK_DIR_NAME записанны логин, пароль и имя каталога соответственно. |
| **Шаг**         | **Ожидаемый результат**                                                                   |
| Нажать правой кнопкой мыши по свободному месту в центральной области | Появился список с элементами вставки |
| Нажать на вариант "Новая папка" | Открылась поле создание новой папки                                       |
| Ввести не пустое название для папки | Текст отобразился верно                                               |
| Нажать на кнопку "Сохранить" | Появилась новая папка с указанным ранее названием                            |

### TestCase #2: Удаление содержимого корзины

| **Номер**       | 2                                                                                                                              |
|:--------------- |:-------------------------------------------------------------------------------------------------------------------------------|
| **Заголовок**   | Удаление каталога.                                                                                                             |
| **Предусловие** | Открыта страница [сайта](https://disk.yandex.ru/client/disk). Пользователь зарегистрирован. В переменных окружения DISK_USERNAME, DISK_PASSWORD, DISK_DIR_NAME записанны логин, пароль и имя каталога соответственно. |
| **Шаг**         | **Ожидаемый результат**                                                                                                        |
| Нажать правой кнопкой мыши по любому каталогу из центральной области | Появился список с выбором действий, которые можно совершить над каталогом |
| Нажать на вариант "Удалить" | Каталог переместился в корзину                                                                                     |
| Нажать правой кнопкой мыши по элементу "корзина" на центральной области | Появился вариант "Очистить Корзину"                                    |
| Нажать на кнопку "Очистить Корзину" | Открылась поле с подтверждением очистки                                                                    |
| Нажать на кнопку "Очистить" | Снизу слева появилось уведомление об очищении корзины                                                              |
